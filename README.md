# High-Cloud-Airlines

# ✈️ 1. Airline Load Factor & Performance Analytics

## 🛠️ Tech Stack

Microsoft Excel | MySQL | Microsoft Power BI | Tableau

## 🎯 Project Overview

Analyzed **110K+ airline flight records containing 64 attributes** to uncover load factor trends, passenger demand patterns, carrier efficiency, and route performance. The analysis supports data-driven airline operations and capacity planning.

## 🔍 Key Analysis & Business Findings

- 📅 **Time-Based Analysis:** Created date and time dimensions, including Year, Month, Quarter, Weekday, and Financial Year.
- 📈 **Load Factor Trends:** Calculated yearly, quarterly, and monthly load factors, increasing from 75.30% in 2008 to 78.12% in 2013.
- 🏆 **Carrier Performance:** Identified top carriers, including Southwest with 3.41M+ and Delta with 2.88M+.
- ✈️ **Carrier Utilization:** Identified the highest reported load factor of 93.33% for Charter Air Transport.
- 🛣️ **Route Performance:** Identified the Chicago–Detroit route as having the highest demand.
- 📆 **Weekday vs. Weekend Analysis:** Compared utilization patterns, which remained relatively stable at approximately 76–77%.
- 📏 **Flight Distance Segmentation:** Categorized flights into Short, Medium, Long, and Ultra-long haul segments.

This project demonstrates how airline data analysis can help organizations:
